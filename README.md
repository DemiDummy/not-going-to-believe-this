# You're Not Going to Believe This

A first-person horror investigation. Northern Arizona, 2003. You're the deputy in a town of 600. You take the calls,
work the scenes with a flashlight, a tape measure and the department's new digital camera, and pin it all to the case
board. The investigation works. That's the problem.

**Play it at https://demidummy.github.io/not-going-to-believe-this/** (desktop browser, keyboard and mouse, headphones, about an hour).

WASD to walk, Shift to run, E to use, F flashlight, C camera, T tape measure, R to answer the radio, Tab for the
notebook, Esc to pause.

This repo only holds the built game. It's published from a private source repo by `tools/release-pages.sh`.
